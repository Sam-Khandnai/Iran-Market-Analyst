# 📈 تحلیل‌گر هوشمند بورس ایران، طلا و ارز

سیستم چندعاملی (Multi-Agent) تحلیل تکنیکال، بنیادی و ریسک برای **بورس اوراق بهادار تهران**، به‌علاوه تحلیل **طلا، سکه و ارز** — بر پایه داده‌های زنده و واقعی، بدون هیچ داده ساختگی.

> ⚠️ **توجه مهم**: خروجی این سیستم یک **تحلیل پژوهشی مبتنی بر داده** است، نه توصیه سرمایه‌گذاری. تصمیم نهایی همیشه با شماست.

## 🎯 این پروژه چه کاری انجام می‌دهد؟

کاربر یک نماد بورسی (مثل «فولاد») یا یک دارایی (مثل «دلار» یا «سکه امامی») را وارد می‌کند و سیستم:

1. داده واقعی و زنده را از منبع رسمی دریافت می‌کند (بورس تهران از **TSETMC**، طلا/ارز از **TGJU** و **Navasan**)
2. چند تحلیل مستقل و **کاملاً قطعی** (بدون هوش مصنوعی) روی داده انجام می‌دهد: تکنیکال، بنیادی، وضعیت بازار، ریسک
3. نتایج را با یک موتور تصمیم‌گیری ترکیب و اعتبارسنجی متقابل می‌کند
4. یک مدل زبانی (LLM) فقط برای **نوشتن خلاصه قابل‌فهم فارسی** به کار می‌رود — هرگز برای تولید سیگنال خرید/فروش
5. نتیجه را در یک داشبورد وب مدرن و تیره (Dark Mode) به‌صورت زنده (Streaming) نمایش می‌دهد

### ویژگی‌های کلیدی

- ✅ تحلیل تکنیکال (RSI, MACD, Bollinger Bands, SMA/EMA, ATR, Stochastic)
- ✅ تحلیل بنیادی (P/E, P/B, رشد سود، حاشیه سود، اهرم مالی)
- ✅ تحلیل وضعیت بازار و صنعت + جریان پول حقیقی/حقوقی
- ✅ ارزیابی ریسک چندبعدی
- ✅ تحلیل طلا، سکه و ارز با تاریخچه دوساله
- ✅ جست‌وجوی اسناد خبری/مالی با RAG (Retrieval-Augmented Generation)
- ✅ نمودار قیمت تعاملی
- ✅ رابط کاربری فارسی، تم تیره، پاسخ‌دهی زنده (Streaming) شبیه ChatGPT

## 🚀 راه‌اندازی گام‌به‌گام

### گام ۱: دریافت کد پروژه

```bash
git clone <آدرس-ریپازیتوری-شما>
cd market-analyst
```

### گام ۲: راه‌اندازی دیتابیس (Postgres)

پروژه از Docker برای اجرای دیتابیس استفاده می‌کند، پس نیازی به نصب دستی Postgres نیست:

```bash
docker compose up -d
```

برای اطمینان از روشن بودن:
```bash
docker compose ps
```
باید سرویس `db` را با وضعیت `Up` ببینید.

### گام ۳: نصب وابستگی‌های بک‌اند (Python)

```bash
uv sync
```

این دستور تمام کتابخانه‌های لازم را در یک محیط مجازی (`.venv`) نصب می‌کند.

### گام ۴: تنظیم فایل محیطی (.env)

فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید:

```bash
cp .env.example .env
```

سپس فایل `.env` را با یک ویرایشگر متن (مثل Notepad یا VS Code) باز کنید و کلیدهای API را طبق بخش [گرفتن کلیدهای API](#-گرفتن-کلیدهای-api) پر کنید.

### گام ۵: ساخت جداول دیتابیس

```bash
uv run alembic upgrade head
```

### گام ۶: (اختیاری ولی توصیه‌شده) پر کردن تاریخچه طلا/ارز

برای اینکه تحلیل طلا و ارز از همان ابتدا دقیق باشد (نه فقط یک روز داده):

```bash
uv run python scripts/backfill_asset_history.py
```

این دستور تاریخچه دوساله دلار، یورو، درهم، طلا، انس جهانی و انواع سکه را از TGJU دریافت و ذخیره می‌کند (چند دقیقه طول می‌کشد).

### گام ۷: نصب وابستگی‌های فرانت‌اند (React)

```bash
cd frontend
npm install
```

فایل `.env` را در همین پوشه (`frontend/`) بسازید:
```bash
echo "VITE_API_URL=http://localhost:8000" > .env
```

## 🔑 گرفتن کلیدهای API

### ۱. کلید LLM (برای تولید خلاصه تحلیل هوشمند)

پروژه از سرویس **GapGPT** استفاده می‌کند (سازگار با API اوپن‌ای‌آی، قیمت مناسب‌تر برای کاربران ایرانی):

1. به آدرس [gapgpt.app](https://gapgpt.app/) بروید
2. ثبت‌نام کرده و یک کلید API (API Key) بسازید
3. مقدار زیر را در فایل `.env` وارد کنید:

```dotenv
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxx
MODEL_NAME=deepseek-v4.1-flash
OPENAI_BASE_URL=https://api.gapgpt.app/v1
```

> ✅ **نکته مهم**: اگر این کلید را وارد نکنید، سیستم **از کار نمی‌افتد** — به‌جای خلاصه هوشمند، یک خلاصه ساده و آماده (Template) نمایش داده می‌شود. یعنی حتی بدون کلید LLM هم می‌توانید امتیازها، سیگنال و نمودار را ببینید.

### ۲. کلید Navasan (برای قیمت لحظه‌ای طلا و ارز)

1. به ربات تلگرام [@navasan_contact_bot](https://t.me/navasan_contact_bot) پیام دهید و یک کلید رایگان یا اشتراکی دریافت کنید
2. مقدار را در `.env` وارد کنید:

```dotenv
NAVASAN_API_KEY=your_key_here
```

> این کلید فقط برای **قیمت لحظه‌ای** لازم است؛ تاریخچه طلا/ارز از TGJU و بدون نیاز به کلید دریافت می‌شود.

### نمونه کامل فایل `.env`

```dotenv
# LLM (GapGPT)
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxx
MODEL_NAME=deepseek-v4.1-flash
OPENAI_BASE_URL=https://api.gapgpt.app/v1

# قیمت لحظه‌ای طلا و ارز
NAVASAN_API_KEY=your_key_here

# تنظیمات TSETMC (پیش‌فرض، نیازی به تغییر ندارد)
MA_TSETMC_API_URL=https://cdn.tsetmc.com/api
MA_TSETMC_BASE_URL=https://www.tsetmc.com

# دیتابیس (پیش‌فرض Docker Compose)
MA_DATABASE_URL=postgresql+asyncpg://analyst:analyst@localhost:5432/analyst

# تنظیمات عمومی
MA_ENVIRONMENT=dev
MA_LOG_LEVEL=INFO
MA_HTTP_TIMEOUT_SECONDS=20
MA_HTTP_MAX_RETRIES=3
MA_CACHE_TTL_HOURS=6
MA_RETRY_BACKOFF_SECONDS=1.0
MA_USE_MCP=false
```

## ▶️ اجرای پروژه

هر بار که می‌خواهید پروژه را اجرا کنید، **دو ترمینال جدا** باز کنید:

## 🖥 نحوه استفاده

### تحلیل سهام بورس

1. روی تب **«بورس»** کلیک کنید
2. نام نماد را تایپ کنید (مثل «فولاد») یا از چیپ‌های نمادهای محبوب یکی را انتخاب کنید
3. روی دکمه **«تحلیل»** بزنید
4. مراحل تحلیل به‌صورت زنده نمایش داده می‌شود (دریافت داده → تحلیل تکنیکال → بنیادی → ریسک → تصمیم‌گیری → توضیح)
5. در پایان: امتیازهای تکنیکال/بنیادی/بازار/ریسک، سیگنال نهایی، خلاصه هوشمند، شواهد و نمودار قیمت نمایش داده می‌شود

### تحلیل طلا، سکه و ارز

1. روی تب **«طلا و سکه»** یا **«ارز»** کلیک کنید
2. دارایی مورد نظر را از لیست انتخاب کرده و **«تحلیل»** بزنید
3. همان ساختار تحلیل بورس (امتیاز روند، مومنتوم، نوسان‌پذیری، سیگنال، نمودار) نمایش داده می‌شود

## 🔧 رفع مشکلات رایج

### «Connect call failed» یا خطای اتصال به پورت ۵۴۳۲

دیتابیس روشن نیست:
```bash
docker compose up -d
docker compose ps
```

### پیام «داده‌ای برای این دارایی ثبت نشده است»

تاریخچه طلا/ارز backfill نشده:
```bash
uv run python scripts/backfill_asset_history.py
```

### تحلیل هوشمند فقط یک متن ساده و تکراری نشان می‌دهد

کلید `OPENAI_API_KEY` در `.env` خالی یا اشتباه است. سیستم به‌جای کرش کردن، خلاصه پیش‌فرض نشان می‌دهد. کلید GapGPT را طبق بخش بالا وارد کنید و بک‌اند را ری‌استارت کنید.

### صفحه فرانت‌اند سفید است

1. کنسول مرورگر را باز کنید (کلید `F12`) و خطای قرمز را بخوانید
2. مطمئن شوید بک‌اند در حال اجراست (`http://localhost:8000/health` باید `{"status":"ok"}` برگرداند)
3. فایل `frontend/.env` را چک کنید که `VITE_API_URL=http://localhost:8000` داشته باشد

### خطای «relation does not exist» از دیتابیس

مهاجرت‌ها اجرا نشده‌اند:
```bash
uv run alembic upgrade head
```

### تست‌ها را چطور اجرا کنم؟

```bash
uv run pytest -v
uv run ruff check src tests --fix
```
